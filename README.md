# whisper-vulkan-build

Builds unmodified [whisper.cpp](https://github.com/ggml-org/whisper.cpp) v1.9.4 for Windows x64 with the Vulkan backend (Intel/AMD integrated GPUs), and publishes `whisper-cli.exe` / `whisper-server.exe` as a Release.
Only the build recipe lives here. whisper.cpp is MIT licensed.
